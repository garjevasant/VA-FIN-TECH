# VA FinTech Website

Static website project structure:

```text
VA FinTech/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    ├── va.png
    ├── hero-fintech.png
    ├── services-banner.png
    ├── calculators-tools.png
    ├── ads-branding.png
    ├── contact-support.png
    └── footer-visual.png
```

- `index.html`: Page markup and content.
- `css/style.css`: All layout, responsive design, animations, and visual styling.
- `js/main.js`: Interactions, calculators, counters, WhatsApp behavior, particles, and service animations.
- `images/`: Logo and generated website visuals.
